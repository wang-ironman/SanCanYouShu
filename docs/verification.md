3. 从早餐进入换菜列表，替换一道菜。持久菜单编号更新，备菜重新汇总（该夹具由 110 项变为 112 项），已备状态归零。

## 验证边界

- 未接入用户的真实模型服务；未验证真实截图识别准确率及各供应商模型的实际菜单质量。假服务仅验证兼容接口协议。
- 未进行安卓实体手机测试；Android 8.0–14 和 Android 16 未逐版本运行验证。最低版本来自项目配置与使用的 API 范围。
- 菜谱中未注明人数时以 2 人估算，未量化项需要查看原方。菜单搭配是家庭使用规则，尚未实现精确营养计算、预算优化和库存抵扣。
- 本地个人首版，没有云同步或数据导出；卸载和清除应用数据会删除本机记录。
